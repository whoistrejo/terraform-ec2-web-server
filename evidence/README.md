# Deployment evidence

This folder starts intentionally empty except for a checklist. It does not contain fabricated AWS screenshots or deployment results.

Add your own evidence after running the lab:
- `terraform-version.txt`
- `terraform-fmt-validate.txt`
- `plan-summary-redacted.txt`
- `deployment-notes.md`
- Screenshots in `screenshots/`

Record the AWS account alias or a redacted account reference, region, date, resources created, verification commands and cleanup result. Never upload Terraform state, credentials, private keys, or unredacted logs.
